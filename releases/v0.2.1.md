# v0.2.1

- Upgrade `featbit-server-sdk` and the OpenTelemetry adapter to 0.2.1.
- Update the provider package and installation instructions to 0.2.1.
- Adapt retained evaluation-event construction to the core SDK's four-argument API.
- Verify that evaluation events omit `sendToExperiment` even when server data contains legacy experiment metadata, and update the telemetry example to require the removed experiment attribute to be absent.

## Compatibility

The core SDK 0.2.1 removes public APIs despite the patch version. Applications using
`FbEvaluationEvent::new` must remove the previous `send_to_experiment` argument;
the remaining arguments are `(flag_key, variation_id, variation_value, insights_enabled)`.
The `FbEvaluationEvent::send_to_experiment()` and
`EvaluationObservation::send_to_experiment()` methods are removed, and the OpenTelemetry
attribute `featbit.evaluation.send_to_experiment` is no longer emitted.

Legacy server experiment metadata is ignored. Ordinary targeting and percentage
rollouts remain unchanged. The provider's OpenFeature API and its requirement for
`open-feature` 0.3.0 are unchanged.
